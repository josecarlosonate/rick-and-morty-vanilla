# Rick and Morty Characters

[English](#english) | [Español](#español)

---

## English

A web application built with **Vanilla JavaScript** that consumes the Rick and Morty API to explore characters from the series.

The application displays **20 random characters**, allows users to **search characters by name**, and provides a **detail view** for each character.

### Features

- Display 20 random characters from the Rick and Morty API
- Search characters by name
- Character detail view
- Display character information:
  - Name
  - Status
  - Species
  - Gender
  - Origin
- Loading and error states
- Responsive interface
- Client-side API consumption using `fetch`
- ES Modules with `import` / `export`

### Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- Bootstrap 5
- Rick and Morty REST API

### Project Structure

```text
rick-and-morty-vanilla/
├── css/
│   └── styles.css
├── js/
│   ├── api.js
│   ├── app.js
│   └── character.js
├── character.html
├── index.html
└── README.md
```

### How to Run

Clone the repository:

```bash
git clone https://github.com/josecarlosonate/rick-and-morty-vanilla.git
```

Enter the project directory:

```bash
cd rick-and-morty-vanilla
```

Run a local server. For example, using PHP:

```bash
php -S localhost:8000
```

Then open:

```text
http://localhost:8000
```

### API

This project uses the Rick and Morty API:

```text
https://rickandmortyapi.com/api
```

## Español

Aplicación web desarrollada con **JavaScript Vanilla** que consume la API de Rick and Morty para explorar los personajes de la serie.

La aplicación muestra **20 personajes aleatorios**, permite **buscar personajes por nombre** y consultar una **vista detallada** de cada personaje.

### Funcionalidades

- Mostrar 20 personajes aleatorios de la API de Rick and Morty
- Buscar personajes por nombre
- Vista de detalle de cada personaje
- Mostrar información del personaje:
  - Nombre
  - Estado
  - Especie
  - Género
  - Origen
- Estados de carga y manejo de errores
- Interfaz responsive
- Consumo de API mediante `fetch`
- ES Modules mediante `import` / `export`

### Tecnologías

- CSS3
- JavaScript (ES6+)
